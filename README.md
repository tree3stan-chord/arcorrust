# arcorrust

Terminal-based virtual instrument playground with real-time synthesis and built-in sequencer.

## Features

- Real-time audio synthesis with multiple oscillator types
- Terminal UI built with ratatui
- Effects processing (filters, delay, reverb)
- Pattern sequencer
- Preset management
- Audio recording

## Installation

### Arch Linux (AUR)

```bash
yay -S arco
```

### Homebrew (MacOS & Linux)

```bash
brew tap tree3stan-chord/tap  
brew install arco  
```

### From source

```bash
cargo build --release
```

## Usage

```bash
arco
```
